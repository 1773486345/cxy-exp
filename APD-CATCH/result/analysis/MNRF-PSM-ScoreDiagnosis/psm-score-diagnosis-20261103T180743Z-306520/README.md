# PSM Full GMM：正常高分与校准上尾

## 结论

Full GMM 对异常有排序能力（ROC-AUC=0.744926，AP=0.437281），但当前固定校准阈值下误报高：严格 `score > threshold=15.702126` 得到 TP/FP/FN/TN=14694/17305/9684/45967，正常点 FPR=27.35%。最强的直接解释是**校准与后续测试正常分数尾部不匹配**：校准 q99.5 阈值为 15.702，而测试正常分数中位数/q75/q90/q95/q99 为 1.643/166.165/495.950/638.478/644.935。测试正常高分并不是由校准上尾的标签污染解释：按保存的 seq_len=192 冻结窗口核对，校准分数最高 66 点中端点异常 0、上下文含异常 0。

时间诊断显示误报高度成段：固定等长测试十分位 4、6、7、8 合计 17,157/17,305 个 FP（99.1%）；第 7 十分位 5,500/5,500 个正常评分点都报警。最长连续 FP 段为 4,366 个端点，前 8 个连续段合计 15,789 个点（91.2%）。其中 14,899 个 FP 的 192 步历史窗没有标注异常，2,406 个窗口含异常标签；异常上下文不能解释主体误报。十分位只按官方测试轴等分，CSV 同时报端点标签和窗口上下文，不跨冻结边界拼接。

在测试误报上，变量最大值主导份额为 feature_3 58.7%, feature_1 41.0%, feature_20 0.2%；真阳性上为 feature_3 51.1%, feature_1 47.5%, feature_9 0.8%；漏报上为 feature_1 32.2%, feature_12 14.6%, feature_9 12.5%。正常点最高分 1% 由 feature_3 100.0%, feature_0 0.0%, feature_1 0.0% 主导。按既有变量分析，FP 中 feature_1/feature_3 合计 99.7%；top-1% 高分正常归因集中在 feature_3。feature_3 校准 center/scale=20.711/22.336，正常点 raw NLL median/q90/q99=-19.276/11,089.854/14,425.818，FP median/q99=10,272.086/14,559.155，FP 标准化值 median/q99=458.967/650.904。feature_1 center/scale=-6.031/16.158，FP raw NLL median/q90/q99=1.428/7,054.958/7,962.999，标准化值 median/q99=0.462/493.180。故 feature_3 提供更持续的异常高尾，feature_1 是另一批点上的次要 max 主导者；两者都没有触发 score MAD floor；此前 scale 诊断中输入尺度 floor 也未触发。因此当前证据不支持“标准化地板触发导致误报”。

**下一步最值得做的一项修改**：在不接触测试标签的条件下，改进校准样本对时间/工况尾部分布的代表性，而非先改编码器。做一个严格冻结表示、GMM、变量聚合与 q=.995 的时间分块校准对照：从合法训练侧预留多个按时间连续的校准块，预先固定如何合并其分数分布；与现有 pooled-calibration 阈值比较跨块阈值稳定性和后续盲测 FPR/召回。测试标签只作最终评价。若后续正常段仍超出校准分布，则归为部署漂移，不用测试标签调阈值。全体 Full-mean 的 FPR 仅由 27.35% 变为 27.12%，不支持单纯把 max 改 mean 是当前误报的充分修复；diag-mean FPR 较低但同时更换协方差与聚合并牺牲召回，不能据此归因。

### 证据边界

- **直接证实**：阈值和分数复算通过；校准上尾无异常端点或异常历史窗；测试正常高分远超校准尾；误报 max 归因集中于 feature_1/feature_3；score MAD floor 未触发。
- **有支持但未证因果**：正常测试阶段出现校准期未覆盖的分数尾部/工况变化；max 让 feature_1 或 feature_3 的局部高 NLL直接控制总分。
- **仍无法区分**：变化源于正常工况漂移、冻结表示局部外推，还是 GMM 联合密度尾部失配。`feature_1/feature_3` 是冻结输入命名，不擅自解释为物理变量。现有校准窗口正常只能排除该校准上尾被已标注异常污染，不能证明整个校准期和测试期过程分布相同。

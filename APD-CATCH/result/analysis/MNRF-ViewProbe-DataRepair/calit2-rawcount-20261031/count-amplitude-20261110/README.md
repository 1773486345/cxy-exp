## 唯一新增分数

直接读取 IF/PCA 已保存、逐项相同的 `normalization.npz`，使用其绑定的 **1,710行 [0, 1710)** 冻结训练行；不重新估计参数。以下均值和尺度顺序是 [9, 7]：

```text
mean  = [3.530994152046784, 3.3076023391812868]
scale = [6.2815918434490525, 5.421324646051813]
z9 = (count9 - mean[0]) / scale[0]
z7 = (count7 - mean[1]) / scale[1]
score = max(abs(z9), abs(z7))
```

均值/尺度直接用于float64算术；加载后的计数float32与源完整特征身份一致。两个字段均保留，未按测试成绩选择变量、方向、权重或公式。用冻结训练行复核保存均值/标准差仅作一致性检查，没有写回或替换统计。没有为幅度分数生成新的独立校准阈值或正式报警成绩。

## 最多183个误报：历史测试集上的探索性排序诊断

各方法独立枚举保存连续分数的严格 `score > threshold` 工作点，并列分数整组进入/退出；在FP≤183中先取最高TP，同TP再取最少FP。183/2,259约为8.10%，不要求每个方法恰好用满预算。不插值，不重新校准。AP使用 sklearn `average_precision_score`，在全部2,329共同点上计算。

| Isolation Forest | 0.253774 | 40 | 154 | 57.14% | 6.82% | 27 |

目标集合定义为：同一预算下 `label=1 AND IF报警 AND Full不报警`。27点中，共同找回16、仅幅度10、仅PCA1（全局坐标3780）、两者都未找回0。幅度未找回的恰是PCA独有的3780点。找回26个是对该目标集合的覆盖，不能当成在Full的23个TP上无条件净增26个；方法的检出集合并不嵌套。
